# 🏥 Healthcare Data Analytics & Dashboard (Excel)

An end-to-end Healthcare Data Analysis project built entirely in **Microsoft Excel**.
This project covers the full data lifecycle—from raw patient data ingestion and cleaning to advanced transformation, exploratory analysis, key metrics calculation, and an interactive executive dashboard.

The project converts raw healthcare records into a structured, interactive analysis that supports data-driven understanding of patient health conditions, treatment history, and healthcare costs.

Tools Used

Data Cleaning and Formatting
Excel Formulas
